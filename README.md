# DCC-Editor

**DCC Editor** is a software developed in collaboration with a high school scholarship student from Inmetro called Gustavo Chieza. 

The tool applies the idea of a ***self-describing interface***, developed by me for the **TimeFTP** application, and uses it in the context of DCCs (Digital Calibration Certificates). 

In this way, DCC Editor can read a DCC XML document compatible with the PTB XML schema and display the DCC data as a visual form in a graphical interface. Thus, the DCC structure itself defines the form. 

In addition, the DCC structure can be edited and stored under a different name and the software can check the PTB XML schema version and DCC compatibility.
