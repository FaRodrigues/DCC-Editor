# DCC-Editor

**DCC Editor** is a software developed in collaboration with high school scholarship student from Inmetro called Gustavo Chieza. 

The tool applies the idea of a ***self-describing interface***, developed by me for the **TimeFTP** application, and uses it in the context of DCCs (Digital Calibration Certificates). 

In this way, DCC Editor can read a DCC XML document compatible with the PTB XML schema and display the DCC data as a visual form in a graphical interface. Thus, the DCC structure itself defines the user interface form. 

In addition, the DCC structure can be edited and stored under a different name and the software can check the PTB XML schema version and DCC compatibility.

# Getting Started

## Install and Run Dependencies

If you have just downloaded the project and it fails due to missing modules, you may need to install its requirements first:

1. Install dependencies: python -m pip install -r requirements.txt.
2. Run the script: python DCC Editor.py
